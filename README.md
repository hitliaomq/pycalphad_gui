# pycalphad GUI

pycalphad 的图形界面。数据库加载 → 元素周期表浏览 → 相列表排除 → 相图与属性绘制 →
图的交互标注 → 高通量计算 → 结果导出，全部在一个窗口里完成。

设计细节、API 陷阱清单与取舍理由见 **[ARCHITECTURE.md](ARCHITECTURE.md)**。

## 环境要求

- Python 3.10 ~ 3.13（在 3.12 / PyQt6 6.11 / pycalphad 0.11.2 上验证）
- 系统装过 Qt 运行库（PyQt6 自带，一般无需额外配置）

## 安装

```bash
pip install -r requirements.txt -i https://pypi.org/simple
# 或者可编辑安装整个包：
# pip install -e .
```

## 运行

在项目根目录（也就是 `pycalphad_gui/` 这个文件夹）下，任选一条，起的是同一个窗口：

```bash
python pycalphad_gui/app.py                        # 最省事：直接跑脚本
python -m pycalphad_gui                            # 以包方式运行
python pycalphad_gui/__main__.py                   # 直接把入口文件路径交给解释器
pycalphad-gui                                      # 装过 pip install -e . 后用控制台脚本
python -m pycalphad_gui path/to/database.tdb       # 顺便带路径启动（可选）
```

启动后**不会自动载入任何数据库**，请在界面里选择打开：

- 工具栏左上角的 **「打开数据库…」** 按钮（快捷键 `Ctrl+O`）
- 或 `文件 → 打开数据库…`
- 或把 `.tdb` / `.dat` 文件**直接拖进窗口**

上次打开的目录会被记住，下次启动直接定位到那个文件夹。
载入前三个功能页（相图 / 属性 / 高通量）保持禁用，不会让你点空；
**「数字化相图」页不需要数据库**，随时可用（它处理的是图片，不是热力学计算）。
「导入图像」同样始终可用，拖一张图进来即可开始。

### ❌ 常见错误：`attempted relative import with no known parent package`

```
Traceback (most recent call last):
  File "...\pycalphad_gui\__main__.py", line 4, in <module>
    from .app import main
ImportError: attempted relative import with no known parent package
```

不是代码坏了，是**启动方式不对**。直接把包内部的 `.py` 文件路径交给解释器时，
那个文件属于"脚本"，此时 `__package__` 是 `''`（不是包名），`importlib` 会拒绝
相对导入 `from .app import ...`。这跟 PyQt6 无关，纯 Python 的导入规则。

| 你写的 | 结果 |
|---|---|
| `python pycalphad_gui/app.py` | ✅ 正确 |
| `python pycalphad_gui/__main__.py` | ✅ 正确（入口内部做了 sys.path 补位 + 绝对导入回退） |
| `python pycalphad_gui/                  → python app.py` | ✅ 在包目录里敲也行 |
| `python -m pycalphad_gui` | ✅ 正确 |
| `python pycalphad_gui/__init__.py` | ❌ 上面这个报错 |

`app.py` 与 `__main__.py` 都做了双模式导入，`tests/test_entry.py` 三条路径都锁了回归。

**另一个坑**：从工作区根目录敲 `python app.py` 会报 "can't find file 'app.py'" ——
因为 `app.py` 在 `pycalphad_gui/pycalphad_gui/app.py`，不在 `pycalphad_gui/app.py`。
要么 `cd pycalphad_gui` 再敲 `python pycalphad_gui/app.py`，要么就用 `python -m pycalphad_gui`。

## 界面怎么用

### 1. 加载数据库
点上面的打开入口，支持 Thermo-Calc 的 `.tdb` / `.dat`。
加载后左下角会显示元素数、相数与读取耗时；若库里用了非标准写法会给出警告。

### 2. 元素周期表
- 所有元素始终显示：库内元素**蓝色描边高亮**，库外元素灰化但仍可选（有些数据库元素列表不全，以你的判断为准）。
- 点击元素选中，**Shift + 点击**可按原子序数框选一段（例如 Shift 点 Al 再点 Zn 选中整个范围）。
- 所有元素常显：库内元素蓝框高亮，库外灰化但仍可点选（有些库的元素列表不全，用户比程序更清楚）；
- 单击选中单个元素，**Shift+点击**以上次点击为锚点框选整个区间；
- `VA`（空位）与 `/-`（电子气）两个伪物种格在第 1 周期的空白处（可直接点选；空位也会作为 endmember 自动进计算组分）；
- 面板高度按整表给足，无需滚动即可看全（含镧系 / 锕系两行）。

**勾选即全局约束。** 右侧各页的候选一律以这里的勾选为准，与库里有几个元素无关：

| 位置 | 勾选 Ti + V 后 |
|---|---|
| 相图 / 高通量 · 扫描维度 | 只有 `Ti`、`V`、`T`、`P`、`N` |
| 属性 · 扫描轴 | 只有 `T`、`Ti`、`V` |
| Scheil · 成分输入 | 只有 `Ti`、`V` 两行摩尔分数 |

对 COST507 这类 20 元素库，勾了 Ti / V 就不会再冒出 AL、CU、MG 让你误扫。
勾选库外元素（如 V–Zr 库里点 Au）不会让软件崩，状态栏会明说"已忽略 AU：不在数据库中"。
真一个元素都没勾时，状态栏的体系标签显示 `—（请先在周期表勾选元素）`，
此时点计算会被拦下，不会拿一个空壳体系去算。

预选规则：**二元库**载入时自动预选它的两个元素（开箱即可算）；**多元素库**
载入后不预选任何元素，由你自己勾。周期表正上方有一行"已勾选：Ti + V"实时摘要
（旁边就是"清空"按钮），勾了什么一目了然。

### 3. 相列表
勾选决定哪些相参与计算（反选即排除）。支持搜索、全选 / 全不选 / 反选。
库里写着但你不想要的相，在这里剔掉即可，不必改 TDB 文件。

### 4. 相图
条件面板里每一行是一个**扫描维度**（变量 + 起点 + 终点 + 步长），
「固定条件」里放没在扫描的 T / P。相图类型决定维度数量：

| 相图类型 | 组分扫描 | 外部条件扫描 |
|---|---|---|
| 二元 T–X（ZPFE） | 恰好 1 | 恰好 1（T 或 P） |
| 三元等温等压截面 | 恰好 2 | 0（温度固定） |
| 二元平衡态 (eqplot) | 恰好 1 | 恰好 1 |
| 三元平衡态 (eqplot) | 恰好 2 | 0 |

不满足会被**前置拦下并给出中文修正建议**，不会丢一个英文堆栈给你。

**平衡态 (eqplot) 的两个轴都由引擎显式指定**：`x` 取第一个组分扫描轴，`y` 取第二个
组分扫描轴（三元）或被扫描的 T/P（二元）。不能让 eqplot 自动补 `y`——它的
`indep_comps` 按变量名排序，当 `x` 正好等于排序后的第二个独立组分时，`y` 会被补成
同一个变量，两轴同名、数据退化成一条对角线（T62）。三元投影还会放大画布并把
y 轴标签移到三角形外侧，避免压在刻度数字上。

**三元截面需要勾满三个元素**：两个作扫描轴，第三个的摩尔分数由 N=1 隐式确定为
1 − X₁ − X₂（pycalphad 的 TernaryStrategy 硬性要求，只勾两个元素会被友好拦截）。
绘制策略是"映射优先、网格兜底"：先走 pycalphad 的映射算法（TernaryStrategy +
plot_ternary，官方 ternplot 效果：绿色 tie line 扇形、相色边界与相图例）；若映射
未收敛，自动退回**网格法**——一次向量化平衡求解整个三角网格，图题会标注
"（网格法）"。勾选"填色相区（官网 plot_shaded_ternary 风格）"后：映射收敛时按
官方文档的 plot_shaded_ternary 填色（单相区淡蓝底、两相区白色 tie line 多边形、
三相区黄色三角形黑描边）；映射未收敛时退网格法填色视图（Delaunay 剖分铺满
三角形、单相区按相色填充）。"显示 tie line"勾选框对两种样式都生效。

勾选"自动生成映射起点（三元截面）"后按[官方文档](https://pycalphad.org/docs/latest/examples/1_Phase_Diagrams/2_TernaryExamples.html)
的映射流程走：显式 `generate_automatic_starting_points()` 沿三条边搜起点；
若映射仍为空（相区不与边相连的体系，如 Al-Cu-Y 高温截面），自动在三角形
内部补节点（`add_nodes_from_conditions`）重映射一次——这是官方文档"加自定
义起点"一节的自动化。

注意：传给 TernaryStrategy 的成分条件必须是 (start, stop, step) 三元组——
传 np.linspace 全量数组会 0 节点收场（T61，连官方 Cr-Fe-Nb 算例都复现）。

### 5. 图的交互（纯鼠标手势，无模式下拉框）
不使用 NavigationToolbar（它会和自建交互抢鼠标事件），**所有标注操作直接在图上完成**，
没有任何"先选模式再点图"的中间步骤：

| 操作 | 行为 |
|---|---|
| 左键单击空白 | 就地放置相标签并弹出输入框，回车确认 / Esc 取消 |
| 左键拖动标签 | 移动标签 |
| Shift + 左键拖动 | 从起点拉一条 tie line，松开落笔 |
| 右键单击 | 删除光标下的标签 / tie line |
| 左键拖动空白 | 框选放大 |
| 右键 / 中键拖动 | 平移 |
| 双击标签 | 就地改名 |
| 双击空白 / Ctrl+R | 复位视图 |
| 滚轮 | 以光标为锚缩放 |
| 拖动图例 | 把 legend 挪到任意位置 |
| Ctrl+L / 工具栏 | 切换对数轴、清除标注、导出图像 |

标注支持中文（matplotlib 字体在启动时切到微软雅黑）；悬停时状态栏会显示当前数据坐标；按 F1 可随时查看手势总览。应用图标为 pycalphad 官方 logo。

### 6. 属性
在「属性」页选属性量（G / H / S / Cp）与扫描轴，起 / 止 / 步长决定采样点。

- **扫描轴选组分**：固定温度由「固定温度 T (K)」给出，画的是该温度下的平衡曲线；
- **扫描轴选 T**：必须再用「固定组分 X」钉住一个组分的摩尔分数，否则体系自由度不为零，
  pycalphad 会直接报错——这个输入框会随扫描轴切换自动启用 / 禁用。

「曲线来源」决定画什么：

| 选项 | 含义 |
|---|---|
| 逐相（每个相一条曲线） | **默认**。每个相单独求解，画的是该相自身的 G / H / S / Cp，含亚稳相；下方相列表可只勾选要看的相 |
| 平衡态（仅最稳定相） | 只画全局平衡态的一条曲线 |
| 逐相 + 平衡态对照 | 逐相曲线 + 平衡态虚线，方便核对哪条在最下方 |

相列表在切到纯平衡态时会自动禁用（那个模式算不出相分解）。某个相因成分容纳不下
等原因算不出来时，不会静默消失，而是在状态栏列出「⚠ 未出曲线的相」。

### 7. 高通量
「高通量」页把各扫描维度展开成笛卡尔积，逐点求解，输出表导出为 CSV / Excel。
可选的并行模式：默认线程池（界面流畅、易取消），也可切进程池吃满多核。
结果表按扫描轴排序，列头为中文；单点失败记进 `failures`，不会被静默丢弃。
如果「最低G」整列是 NaN，说明这些点是"算完了但没有物理解"（温度/成分超出数据库有效区间），
顶部状态栏会一并提示。

### 8. 数字化相图（把别人的图变成你的数据）

手上有文献截图 / 扫描的相图，想拿出来用？导进来，点几下，导出成表。

**导入图像**三条路，任选：

- 工具栏 **「导入图像」**（`Ctrl+Shift+O`），或 `文件 → 导入图像…`
- **「粘贴图像」**（`Ctrl+Shift+V`）直接吃剪贴板里的截图
- 把 `.png / .jpg / .bmp / .tif` **拖进窗口**

导入后主窗口中央显示图片（滚轮缩放、中键拖动平移）；右侧计算面板切到
**「数字化相图」**页，按五步走：

| 步骤 | 做什么 | 要点 |
|---|---|---|
| ① 选类别 | 二元 / 三元 | 决定后续的光标形状与网格线候选角度 |
| ② 标定区域 | 点「开始标定」，再在图上点 3 个角 | **二元**出十字光标；**三元**出三条互成 60° 的线光标。二元点矩形三顶点（左下 / 右下 / 左上）；三元点三角形三个顶点，随后要求填每个顶点对应的组分（默认 1 / 0 / 0 循环） |
| ③ 去除网格线 | 点「去除网格线」 | 与坐标轴近似平行且**贯通整个坐标区域**的直线即网格线；**虚线也认**（判据是最长缺口占比，不是连续长度）。可一键「还原图像」撤销 |
| ④ 标定相区边界 | 「开始新区域」→ 沿边界逐点点击 → 「完成区域」 | 点在边界**附近**即可，程序吸附到最近的墨迹（亚像素质心）；点错了用「撤销上一点」或**右键点该点**删除。完成后弹输入框填相标签（如 `BCC_A2`） |
| ⑤ 生成数据 | 点「生成数据」 | 在区域内铺规则网格，只保留落在多边形内的点，换算成成分后追加进表格 |

**下一个区域的点永远追加在上一个区域的点下面**，表里带 `region` / `phase` 两列，
一眼能分清哪批点属于哪个相区。表格下方可以**导出 CSV**。

技术细节（二元矩形与三元三角形共用同一套三点标定）：

- 二元：三顶点算仿射变换，像素 ↔ (x成分, 温度)；
- 三元：三顶点当作三个组分的基向量，**重心权重直接就是三个摩尔分数**，无需换算；
- 网格线检测走"定向投影 + 分箱找峰"，候选角度由类别确定（二元 0°/90°，三元 0°/60°/120°）；
  判"是否贯通"用**最长缺口 / 跨度 ≤ 10%**，所以虚线不会漏；
- 擦除时按检测到的**实际角度**（不是理论角度，扫描件常有 1° 多偏差）擦条带，
  并做一轮墨迹膨胀补偿，避免留下残影又吃掉真实边界。

### 9. 宏命令（Thermo-Calc 风格脚本）
「宏命令」页提供一套脚本接口：把 OPEN / ELEMENTS / SWEEP / DIAGRAM / PROPERTY /
SCHEIL / ESPEI / HT / EXPORT 等命令写成 `.pcm` 文件，一次运行整条流程。适合重复计算、
课程演示和批量出图——一份宏里可以连续出多张图、多张表。

```text
OPEN database/alzn_mey.tdb
ELEMENTS AL ZN
PHASES LIQUID FCC_A1 HCP_A3
SWEEP ZN 0 1 0.02
SWEEP T 300 1000 5
FIXED P=101325
DIAGRAM BINARY
EXPORT FIGURE output/al_zn.png
```

- 上方下拉框列出 `macros/` 下的全部示例，选中即可载入；点「运行宏」在后台执行，
  日志和结果表实时回到界面；结果图在宏跑完后挂到中央画布（执行期间 worker 还要
  对同一张图做 `EXPORT FIGURE`，提前挂 Qt 画布会跨线程冲突）。
- 命令大小写不敏感，支持 `#` / `//` 注释、`\` 续行、`$变量` 和 `INCLUDE`；
  相对路径按**当前宏文件所在目录**解析。
- 宏里的 `OPEN` 会切换主窗口的数据库，`ELEMENTS` / `PHASES` 会同步回左侧面板。
- 下方的「命令」页是交互式会话：一行一条命令，回车即执行，结果文本直接回显在
  该页，状态（数据库、元素、相、扫描、变量）跨行保留；结果图同样挂到中央画布。
  - 输入 `?` 显示全部命令总览，`OPEN ?`（或 `? OPEN`）查看单条命令的用法、
    说明与示例；未知命令会直接提示。
  - 输入框里按 **Tab** 补全当前词：首列补全命令名/别名，其余按上下文补
    （OPEN/INCLUDE 补文件路径、ELEMENTS 补元素、DIAGRAM 补类型、`=` 后补
    ON/OFF 等）；连续按 Tab 在候选间循环。
  - 上/下方向键翻命令历史；「重置会话」清空状态，下一条命令重新沿用界面当前
    的数据库与元素。界面里换了数据库时会话会自动重置，避免拿旧状态继续算。
- 示例覆盖 pycalphad、scheil、ESPEI 三家的官方例子，说明与限制见
  [`macros/README.md`](macros/README.md)。ESPEI 的 Cu-Mg 示例使用官方教程的
  31 个数据集与 `run_param_gen.yaml` 设置（`TAGS` 排除 idmix/mag 并给熵数据
  0.1 权重，`AICC=LIQUID:HM=1.4,LIQUID:SM=1.4`），生成的 19 个参数与教程一致；
  「ESPEI 拟合」页也有对应的“数据集标签 / AICc 惩罚”输入框。

### 10. 导出
- 图像：PNG / SVG / PDF / JPG，可选 DPI。
- 数据：属性曲线 CSV、高通量结果表 CSV / Excel、**数字化相图点位 CSV**。

### 11. 界面语言（中文 ⇄ English）
- 菜单栏**右上角**的按钮即语言入口（右侧面板可能被隐藏，入口不能跟着藏）；
  默认 **English**，选择会记住（QSettings），下次启动直接生效。
- 实现方式是"一份中文→英文词典 + 整棵控件树遍历"：启动、切换时各扫一遍，
  **只翻词典里有的文本**——元素符号、相名、数值、你自己标注的文字一概不动。
- 图上的轴题 / 标题 / 图例（引擎在后台线程生成的）在挂上画布时就地翻一遍；
  表格**表头**只翻显示，DataFrame 与导出 CSV 仍是原始列名。
- 已知边界：如果某句文案漏翻，多半是它还没进词典——`tests/` 里有一条
  "词典覆盖源码里每一处汉字"的测试会直接点名。

## 已知边界

- `IsoplethStrategy`（等成分截面）在 pycalphad 0.11.2 上多种条件组合均失败，未纳入主线；
  三元"截面"需求由等温等压全截面（ternplot）满足。
- 高通量默认走线程池，受 GIL 限制；需要真并行请开进程池。
- 三元图的对数轴不支持（三角投影不是笛卡尔坐标）。
- 属性页的逐相曲线按"每个相单独求解"给出，是该相在此条件（含亚稳）下的摩尔量；
  它与平衡态曲线的**差**就是该相的相对稳定性，但不等于"相分数 × 平衡态值"。
- 离子液体相（如 vzr_zha-2012.tdb 的 `IONIC_LIQ`）是否激活完全取决于数据库自身参数：
  该库要到 ~2000 K 液相才压过固相，1500 K 以下算不出液相属于库的模型设定，不是程序问题。
- 数字化的精度上限由**原图本身**决定：低分辨率扫描件、粗线、严重倾斜或透视变形的图，
  标定与吸附都会变差。原图越干净（细线、端正、300 dpi 以上）结果越好。
- 数字化**只做几何还原**，不做热力学校验：程序不会判断你标的边界是否满足相律，
  导出的数据请自行核对。
